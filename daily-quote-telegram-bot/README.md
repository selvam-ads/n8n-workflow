# Daily Quote Telegram Bot

An n8n automation workflow that generates and sends a motivational quote to Telegram automatically.

## Features

- Automated daily execution
- AI-generated motivational quotes
- Sends the quote directly to Telegram
- Reduces manual effort
- Easy to customize

## Workflow

Schedule Trigger
→ AI Agent
→ Generate Quote
→ Telegram

## Technologies

- n8n
- AI
- Telegram Bot API

## How It Works

1. The workflow starts automatically at the scheduled time.
2. AI generates a motivational quote.
3. The generated quote is processed.
4. The final quote is sent to Telegram.
